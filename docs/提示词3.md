## 4. 改动清单

> 每项只给要点与文件位置，**完整说明以 `docs/改进3.md` 为准**。

### 第 1 批：P0（卡住玩法）

#### 4.1 教程：修错位 + 扩到两段式 12 步

- 位置：`src/render/tutorial.js:31, 66-84`
- **错位修复**：补 `scroll` 捕获监听；先 `scrollIntoView` 再 `requestAnimationFrame` 读 `rect`；高亮框做视口钳制；目标缺失时居中提示
- **内容扩充**：必看 4 步（动作门控：太阳能 → 废料场 → 资源条）＋ 进阶 8 条（侧边任务：冶炼厂、断电、研究所、升级、拆除、脉冲预警、商路、存档）
- 进度存 `localStorage`，可续、可跳过、可重看
- 教程卡片要避开高亮区（现在固定 `bottom: 28px` 会挡住目标）

#### 4.2 建造卡片点击丢失

- 位置：`hud.js:331, 349-360`
- 根因：`renderBuildList()` 用 `innerHTML =` 整块重建，且**每 tick 调用**，指针按下/抬起之间节点被换掉，`click` 丢失
- 修法：只在"解锁状态变化 / 资源跨阈值 / 选中项变化"时重建；或改事件委托 `closest("[data-building]")`
- 同时：缺料卡片整卡变红（`.unaffordable`），不再只显示小字"缺料"

#### 4.3 芯片死锁

- 位置：`src/data/buildings.js:311-319`
- 研究所成本 `{ metal: 60, chip: 20 }` → 改为 `{ metal: 60, chem: 20 }`
- 芯片留到中后期科技再要求

#### 4.4 终局协议改任务列表

- 位置：`hud.js` 终局渲染
- 六项任务、带进度、未满足前置灰显并说明缺什么、总进度条、可点击跳转
- 三结局按钮移到下方并注明解锁条件

### 第 2 批：P1（交互与节奏）

#### 4.5 删除「拆除模式」

- 删掉建造面板顶部的模式开关；**保留**选中格子的拆除按钮（`hud.js:383`）

#### 4.6 缩放改 Ctrl + 滚轮

- `grid.js` 监听 `wheel`，`{ passive: false }`，仅 `ctrlKey` 时 `preventDefault`
- 以**鼠标位置为锚点**缩放，光标下格子不漂移
- 保留设置面板按钮作为移动端兜底

#### 4.7 存档改为文件导入导出

- 导出：`Blob` + `<a download>`，文件名 `百日之城-存档-YYYYMMDD-HHmm.txt`
- 导入：`<input type="file">` + 拖拽区
- 导入前展示摘要 → 确认 → 自动备份 → 覆盖
- 保留 Base64 文本框作兜底

#### 4.8 日冕脉冲

- 先加观测日志：`本次脉冲：N 座受损，M 座摧毁，总耐久损失 X%`

- 定位后再把无抗性建筑的损伤目标定为 **50%~70% 最大耐久**

#### 4.9 灰烬风暴

- `disaster.js:66-69`：间隔 60s → **180~300s**，持续 15s → 20~30s
- 加灰色粒子（`fx.js`），进入/退出各 0.5s 淡入淡出，粒子 ≤ 120

## 5. 美术与审美专项（本轮重点，不许敷衍）

**目标不是"能看"，是"看不出是 AI 拼的"。**

### 5.1 先查资料，再动手（强制）

开工前必须完成一次参考检索，并在交付报告里写出你参考了什么：

- **WorldBox** 的像素表现：地形块如何堆叠、阴影如何只用 1–2 级明度
- **Aseprite / 像素画基础**：1px 描边、有限色板、抖动（dithering）、拒绝抗锯齿
- **有限色板理论**：为什么 16 色比 64 色更高级
- 参考三家同类网页游戏的 UI 排版（字号层级、留白、栅格）

不允许"凭感觉配色"。

### 5.2 统一规格（硬性）

| 项 | 规格 |
|----|------|
| 网格 | 8px 基准；所有元素坐标与尺寸为 8 的整数倍 |
| 地形 tile | 24×24 |
| 建筑精灵 | 16×16（大建筑 32×32） |
| 描边 | 统一 1px 深色 `#0E1013`，光源统一左上 |
| 阴影 | **不用模糊阴影**，用 1–2px 实心偏移 |
| 全屏色板 | ≤ 24 色 |
| 单图色板 | ≤ 8 色 |
| 缩放 | 仅整数倍，`imageSmoothingEnabled = false` |
| 明度对比 | 建筑与地面明度差 ≥ 25% |

**禁止**：渐变、圆角、模糊、半像素、非整数缩放、真人照片、AI 写实图、从网上扒图。

### 5.3 排版与层级

- 字号三档：12 / 14 / 16，行高 1.5
- 中文用无衬线系统字体，数字与日志才用等宽
- 去掉了全大写 eyebrow 之后，靠**字重 + 颜色**建立层级，不要靠字号堆叠
- 每个面板留白 ≥ 8px，卡片内边距 ≥ 8px

### 5.4 动效质感

| 动效 | 时长 | 说明 |
|------|------|------|
| 建造中 | 0.3s | 自下而上填充，不要缩放弹跳 |
| 建成 | 0.2s | 一次 1px 白闪 |
| 断电 | 0.4s | 整体降低亮度，不要闪红 |
| 脉冲 | 0.5s | 2 帧橙闪 + 轻微位移（≤ 3px） |
| 风暴粒子 | 常驻 | ≤ 120 粒，`prefers-reduced-motion` 时关闭 |

缓动用 `ease-out`，不要 `bounce`。像素游戏里弹跳缓动会显得廉价。

### 5.5 可以分派子 agent，但必须收口

允许把以下工作拆给不同子 agent：

| 子任务 | 产出 |
|--------|------|
| 参考研究 | 1 页文字说明：参考了谁、学什么、不学什么 |
| 色板与网格 | `palette.js` + 规格表 |
| 像素素材 | 地形 / 建筑 / UI / 特效 四组矩阵 |
| UI 排版 | 面板、卡片、弹窗的间距与层级 |
| 动效 | 时长、缓动、粒子参数 |

**但**：色板与网格必须由主 agent 先定死并分发，否则各画各的，拼贴感会比现在更严重。最后由主 agent 做**一致性审查**：同一屏内所有元素的描边、光源、明度必须统一。

### 5.6 审美自审（必须做，且要留证据）

- [ ] 1× 下元素不糊；2× / 3× 下不出现半像素
- [ ] 同一屏统计颜色数 ≤ 24
- [ ] 建筑与地面明度差 ≥ 25%（可用取色器抽查 3 处）
- [ ] 全项目无圆角、无渐变、无模糊阴影
- [ ] 中英混排时字重协调，不再是一整屏等宽
- [ ] **盲测**：把截图发给 3 个人问"这像人做的还是 AI 做的"，至少 2 人说人做的
