## 1. 逐条说明

### 1.1 缩放改为多档位（P1）

**现状**：`grid.js:181-186`

```js
setZoom(zoom) { this.currentZoom = zoom; const size = GRID_SIZE * zoom; ... }
```

`zoom` 是整数 1/2/3，滚轮与捏合都是 `applyZoom(zoom ± 1)`（`grid.js:62, 66`），所以只能三档。

**方案**：

- `zoom` 改为**倍率浮点数**，1.0 = 100%
- 档位要**比现在多**，不必照搬浏览器那套百分比，按像素表现挑一组即可。参考：

```js
// 仅为参考，实际档位可自行调整；关键是"够多、且包含 100%"
export const ZOOM_STEPS = [0.5, 0.67, 0.8, 0.9, 1, 1.1, 1.25, 1.5, 2, 3];
```

- 至少 **8 档**，必须包含 `1`；上下限建议 50% ~ 300%
- Ctrl+滚轮：在档位数组里向前/向后取一格，**不连续变化**
- 初始值 `1`（100%）
- 地图角落显示当前比例（如 `100%`）
- 以鼠标位置为锚点缩放（保持光标下的格子不漂移）

**验收**：档位 ≥ 8；Ctrl+滚轮逐档切换；刷新后保持；100% 时与现在 1× 完全一致。

### 1.2 「整数缩放」改为「地图大小」滑块（P1）

**现状**：`hud.js:533` 显示页里是三个按钮 `1× / 2× / 3×`，节标题叫「整数缩放」。

**方案**：

- 标题改为 **「地图大小」**
- 控件改为 `<input type="range">`，`min=0`、`max=ZOOM_STEPS.length - 1`、`step=1`，按索引映射到档位数组
- 右侧实时显示百分比（`100%`）
- 与 Ctrl+滚轮**共用同一个值**：滑块动，画布动；滚轮动，滑块跟着走
- 滑块拖动时用 `requestAnimationFrame` 节流重绘，不要每个 `input` 事件都全量重绘

**为什么用离散档而不是连续**：像素画在任意比例下会出现像素宽度不均（有的 2px 有的 3px）。固定档位可以让"哪些比例清晰"可控。

**验收**：拖动滑块，地图平滑变化且百分比同步；松开后刷新仍保持。

### 1.3 地面改为不透明像素地砖（P0）

**现状**：`grid.js:268-289` 用 `globalAlpha = 0.18` 的黑色矩形压在原地形上，再叠 0.34 透明描边。所以建筑下面是一圈**半透明灰**，和周围土黄地形混在一起，看起来脏。

**方案**：

1. **删掉两段 `globalAlpha` 叠加**，改为在建筑下方绘制**不透明**的地砖。
2. 在 `assets/sprites/terrain.js` 新增 `FLOOR_TILES`，每张地图一套：

| 地图 | 地砖主色 | 描边 | 点缀 |
|------|----------|------|------|
| 灰烬平原 | `#6E5B4A` 铁灰褐 | `#4E4034` | 2 个 1px 亮点 |
| 锈蚀沼泽 | `#3E4A3A` 湿泥 | `#2A3328` | 1 个苔点 |
| 裂谷矿带 | `#5A5A60` 岩灰 | `#3E3E44` | 1 条裂纹 |
| 永夜冰原 | `#B8C6CC` 冻土 | `#8E9CA2` | 2 个冰晶点 |
| 轨道残骸带 | `#3A4250` 钢板 | `#262C36` | 铆钉 2 点 |
| 月背盆地 | `#5E5A66` 月壤 | `#44404C` | 2 个坑点 |

3. 每块地砖**只用 3 色**（主色 / 描边 / 点缀），保持有限色板。
4. 绘制顺序：地形 → **地砖（不透明）** → 建筑 → 特效。
5. 在建中的建筑不铺地砖，改画 1px 虚线轮廓。
6. 地砖要比原地形**暗 15~20%**，让建筑更突出，但不能透明。

**验收**：截图放大看，建筑底下的格子是**实心色块**，能看出明确的像素边缘，不再透出底下的土地纹理。

### 1.4 面板重构：去 AI 味 + 功能不丢（P0）

**现状问题**（截图可见）：

- `.game-layout` 是 `270px minmax(580px,1fr) 280px`，最小总宽 **1130px**。窗口一窄就横向溢出，**主页面**出现整体滚动条。
- 多个容器各自 `overflow:auto`，还用 `calc(100vh - 250px)` 这类魔法数字，滚动条层层嵌套。
- 视觉上"像 AI 拼的"：间距随手、字号层级靠堆、边线粗细不一、满屏灰字。
- 功能区分散，视线要来回跳。

**目标只有两条**：

1. **主页面不滚动**（滚动只发生在内部列表）
2. **去 AI 味，且现有功能一个不少**

**不规定具体长什么样。** 三栏、两栏、抽屉、侧滑，由实现者按实际内容决定。以下是硬性约束。

#### A. 滚动（硬性）

- `html, body, #app { height: 100dvh; }`，主容器 `overflow: hidden`
- **只允许建造列表与日志内部滚动**，不要出现第三层滚动条
- 删除 `calc(100vh - 250px)` 这类魔法数字，改用 `min-height: 0` + `flex: 1`
- 画布区按可用空间缩放，不出现画布自己的滚动条

#### B. 去 AI 味（重点，逐条对照）

| 症状 | 改法 |
|------|------|
| 间距随手（5/7/13px 混用） | 只用 4 / 8 / 12 / 16 / 24 五档 |
| 字号层级靠堆 | 只用 12 / 14 / 16 三档，靠字重和颜色分层 |
| 边线粗细不一 | 全局统一 1px，禁止 2px 分割线 |
| 圆角混用 | 统一一档（如 8px）或统一直角，二选一 |
| 满屏灰字 | 正文纯黑，次要信息用深灰（见 1.8） |
| 卡片全靠描边 | 背景差 + 1px 边线，不要阴影 |
| 图标文字不对齐 | 统一 flex 居中，禁止用 `vertical-align` 凑 |
| 留白不足 | 面板内边距 ≥ 12px，卡片间距 ≥ 8px |

#### C. 功能不能丢（回归清单）

改造是**重排**不是**删功能**，以下入口改完后必须仍然可用：

- [ ] 建造：7 个类别、卡片列表、选中态、缺料态
- [ ] 地图：区域名、描述、切换区域、地下层 ▲▼
- [ ] 顶栏：能量、数据、日序、脉冲倒计时
- [ ] 科研、网络、终局、设置、成就 五个弹窗
- [ ] 日志流 + 运算中心等级 + 配额
- [ ] 选中格子的详情面板（堆叠 / 地下化 / 拆除）
- [ ] 移动端底部导航

#### D. 尺寸适配

不设固定断点表。只需满足：**从 1920 宽缩到 1024 宽，主页面都不出现整体滚动条**，内容该压缩压缩、该折叠折叠、该收进按钮就收进按钮。

**验收**：

- 1920 / 1440 / 1024 三种宽度下，主页均无整体滚动条
- C 的清单逐项可点
- B 的规范抽查 5 处（间距 / 字号 / 边线）符合要求
- 截图给 3 个人问"这像 AI 生成的吗"，至少 2 人说不是

### 1.7 建造卡片文案（P0）

**现状**：

```
太阳能板 ×2
废钢 11.0
+5 ⚡/s · 供能
不耗电
```

「废钢 11.0」没说是**花掉**还是**产出**，第一眼像"我有 11 个"。

**方案**：成本行加动词前缀，产出/耗电分行带符号：

```
太阳能板 ×2
成本：废钢 11
产出：+5 ⚡/s · 供能
耗电：0
```

要点：

- 成本行统一用「**成本：**」开头，多资源用 `·` 分隔（`成本：废钢 40 · 金属 20`）
- 缺料时整行变红（已有 `.unaffordable`，需确认覆盖到成本行）
- 产出为空的采集/能源建筑，写「产出：—」而不是留空
- 大字号的名称与 `×2` 之间留 8px

**验收**：不看说明书，能一眼分清"要花什么"和"产出什么"。

### 1.8 淡灰文字改纯黑（P0）

**现状**：`style.css` 里 `--muted` 在浅色主题是 `#625e57`（灰褐），大量元素在用它：

- `.stat span`、`.resource-item span`、`.build-time`、`.build-help`
- `.map-description`、`.center-status span`、`.eyebrow`
- `.dialog-intro`、`.tech-node small`、`.map-card p`、`.field`
- `.log-day`、`.achievement-row small`、`.build-energy`

另外还有**透明度压暗**：`.build-card.locked { opacity: .65 }`、`.achievement-row { opacity: .55 }`、`.quest-row.locked { opacity: .48 }`——这些会让黑字变灰。

**方案**：

1. 浅色主题 token 改为：

```css
[data-theme="light"] {
  --text: #111111;
  --text-secondary: #1A1A1A;
  --muted: #333333;      /* 不再是 #625e57 */
  --line: #C9C4BB;
}
```

2. 删掉所有**作用于文字**的 `opacity`，改用颜色区分层级：

```css
.build-card.locked { opacity: 1; color: var(--muted); border-style: dashed; }
.achievement-row { opacity: 1; }
.achievement-row small { color: var(--muted); }
```

3. 保留颜色的语义色（能量青、危险红、科研紫），但**正文一律纯黑**。
4. 深色主题不要跟着改黑——深色底上用 `#F2F2F2`，同样不用灰。
5. 顺手做一次对比度检查：正文与背景 ≥ 4.5:1。

**验收**：浅色主题下截图取色，正文文字 RGB 分量都 ≤ 40；不存在因 `opacity` 而发灰的黑字。

## 2. 我补充的问题

### 2.1 非整数档位的像素取舍（P1）

新增档位里会出现非整数倍（如 0.67、1.1），像素会有"有的格 1px、有的 2px"的轻微不均。

**建议**：

- Canvas 设 `image-rendering: pixelated`，且 `imageSmoothingEnabled = false`
- CSS 宽高**取整到整数像素**：`Math.round(576 * zoom)`
- 在设置里标注：「100% / 200% 最清晰，其他比例为适配窗口」
- 如果无法接受不均，可保留一档「贴合像素」（自动吸附到最近的整数倍）

### 2.2 旧存档的缩放值迁移（P0）

现在存档里 `settings.zoom` 是 `1 | 2 | 3`，新方案是倍率浮点。**必须写迁移**：

```js
// 吸附到最近的合法档位，兼容旧值 1/2/3
function migrateZoom(value) {
  return ZOOM_STEPS.reduce(
    (best, step) => Math.abs(step - value) < Math.abs(best - value) ? step : best,
    ZOOM_STEPS[0]
  );
}
```

如果新档位里保留了 `1 / 2 / 3`，旧档可以直接命中；否则会被吸附到最近的档。无论哪种，都要保证老玩家不会一进游戏画布变成 1px 或 3 倍。

同时 `storage.js` 的 `normalize` 只接受 `[1,2,3]`，要改成校验"是否在 ZOOM_STEPS 里"。

### 2.3 触控捏合与滑块共用档位（P1）

`grid.js:62-67` 现在是 `pinch.zoom ± 1`，改成档位索引 ±1，否则手机上一捏就跳到 50% 或 300%。

### 2.4 面板重构的功能回归清单（P0）

见 1.4-C。重构最容易丢的是这些**事件委托选择器**：

```
data-open / data-mobile / data-layer-step / data-zoom
data-building / data-cell-action / data-map-select / data-map-expand
data-tech / data-settings-tab / data-theme / data-speed / data-fontsize
```

重构后逐个点一遍，缺一个就是回归。

### 2.5 地基像素的批量生成规范（P1）

6 张地图 × 明暗两主题 = 12 套地砖。建议：

- 写成 `buildFloorTile(base, edge, spark)` 的工厂函数，**不要手绘 12 份**
- 每套 24×24，3 色，像素边界对齐 1px
- 生成后在 1× / 2× 下各截一次图，确认没有半像素

### 2.6 明暗主题的一致性（P1）

改 1.8 时注意：`--muted` 在文件里出现了 **三次**（约 9 / 282 / 324 行），分别是基础、某主题覆盖、浅色主题。**只改浅色那一处会失效**，要确认最终生效值。

### 2.8 测试补充（P1）

- 旧存档 `zoom: 2` 迁移后落在合法档位

### 2.9 滑块性能（P2）

拖动滑块会触发连续重绘。用 `requestAnimationFrame` 合并，并避免每次重建地形缓存（只在主题/地图变化时重建）。

### 2.10 排版细节（P2）

- 圆角统一（8px 或 0，二选一），不要一处圆一处直
- 分割线统一 1px，不要 2px
- 图标与文字基线对齐，不要用 `vertical-align: middle` 凑
- 空状态文案居中、12px、纯黑
