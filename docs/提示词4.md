## 0. 你的角色与目标

你是一名资深前端游戏工程师兼像素美术，接手一个已上线的项目做**第四轮迭代**。

本轮重心三个：

1. **修显示与交互**：缩放档位、地图大小滑块、地砖、卡片文案、纯黑文字
2. **重构面板**：主页面不滚动、去 AI 味、功能一个不丢
3. **交之前自己测两轮**：先当程序员审代码，再当纯新手玩一遍

**不是从零重写。** 在现有代码上改，保持架构、保持测试全绿。

## 4. 改动清单

> 要点摘要；完整说明以 `docs/改进4.md` 为准。

### 第 1 批：观感立竿见影（P0）

**4.1 建造卡片文案**（`hud.js` 卡片模板）

```
太阳能板 ×2
成本：废钢 11
产出：+5 ⚡/s · 供能
耗电：0
```

- 成本行必须带「成本：」前缀；多资源用 `·` 分隔
- 产出为空的写「产出：—」
- 缺料时整行变红

**4.2 淡灰文字改纯黑**（`style.css`）

- 浅色主题 `--muted: #333`（原 `#625e57`），`--text: #111`
- 删除所有作用于**文字**的 `opacity`（`.locked` 0.65、`.achievement-row` 0.55 等）
- `--muted` 在文件里出现三次，改完确认最终生效值

**4.3 删除「进阶指引」**（`tutorial.js:324-341`、`hud.js:119`、`style.css`）

- 删面板、`ADVANCED_STEPS`、`renderQuests()`、`tutorialTask` 事件与 toast、`.quest-*` 样式
- 设置「关于」里那句"进阶 8 条"一并删
- **保留**必看 4 步教程

### 第 2 批：显示相关（P1）

**4.4 缩放改为多档位**（`grid.js:62-67, 181-186`）

- `zoom` 改倍率浮点，1.0 = 100%
- ≥ 8 档，必须含 1，上下限 50%~300%；参考 `[0.5, 0.67, 0.8, 0.9, 1, 1.1, 1.25, 1.5, 2, 3]`，可调
- Ctrl+滚轮逐档切换，以鼠标位置为锚点
- 捏合缩放也走同一档位数组
- 地图角落显示当前百分比

**4.5 「整数缩放」→「地图大小」滑块**（`hud.js:533`）

- 标题改为「地图大小」，控件改 `<input type="range">`
- `min=0 / max=ZOOM_STEPS.length - 1 / step=1`
- 百分比实时显示，与滚轮共用同一个值
- 拖动时 rAF 节流

**4.6 地面改不透明像素地砖**（`grid.js:268-289`、`terrain.js`）

- 删除两段 `globalAlpha` 叠加（0.18 / 0.34）
- 新增 `FLOOR_TILES`，每图一套，3 色（主色 / 描边 / 点缀）
- 绘制顺序：地形 → 地砖（不透明）→ 建筑 → 特效
- 在建中不铺地砖，画 1px 虚线轮廓
- 地砖比原地形暗 15~20%，但不透明

**4.7 旧存档 zoom 迁移**（`storage.js`）

```js
function migrateZoom(value) {
  return ZOOM_STEPS.reduce(
    (best, step) => Math.abs(step - value) < Math.abs(best - value) ? step : best,
    ZOOM_STEPS[0]
  );
}
```

### 第 3 批：面板重构（P0，单独一批）

**4.8 面板重构**（`index.html`、`style.css`）

目标只有两条：

1. **主页面不滚动**（滚动只发生在内部列表）
2. **去 AI 味，功能一个不少**

**不规定具体形态。** 三栏、两栏、抽屉都行，你按内容决定。硬约束：

**A. 滚动**

- `html, body, #app { height: 100dvh; }`，主容器 `overflow: hidden`
- 只允许建造列表与日志内部滚动，不出现第三层滚动条
- 删除 `calc(100vh - 250px)` 等魔法数字，改 `min-height: 0` + `flex: 1`
- 画布按可用空间缩放，不出现画布自己的滚动条

**B. 去 AI 味**

| 症状 | 改法 |
|------|------|
| 间距随手（5/7/13px） | 只用 4 / 8 / 12 / 16 / 24 |
| 字号层级靠堆 | 只用 12 / 14 / 16，靠字重与颜色分层 |
| 边线粗细不一 | 统一 1px，禁 2px 分割线 |
| 圆角混用 | 统一一档或统一直角 |
| 满屏灰字 | 正文纯黑，次要深灰 |
| 卡片全靠描边 | 背景差 + 1px 边线，不要阴影 |
| 图标文字不对齐 | 统一 flex 居中 |
| 留白不足 | 内边距 ≥ 12px，卡片间距 ≥ 8px |

**C. 功能不能丢**

建造 7 类别 / 卡片选中与缺料态 / 地图切换 / 地下层 ▲▼ / 顶栏四项数据 / 科研·网络·终局·设置·成就 / 日志与配额 / 格子详情（堆叠·地下化·拆除）/ 移动端底部导航。

**D. 尺寸**

不设断点表。只要 **1920 → 1024 宽，主页都不出现整体滚动条**。

## 5. 视觉规范（本轮重点）

- 8px 网格对齐；地形 24×24；建筑 16×16
- 全屏色板 ≤ 24 色；单图 ≤ 8 色；地砖每套 3 色
- 统一 1px 描边，光源统一左上
- **禁止**：渐变、模糊阴影、圆角混用、半透明压暗、非整数缩放、真人图、网图
- 缩放：`image-rendering: pixelated`，CSS 尺寸 `Math.round(576 * zoom)`
- 排版：间距 4/8/12/16/24，字号 12/14/16，行高 1.5
- 动效：建造 0.3s、脉冲 0.5s，粒子 ≤ 120，`prefers-reduced-motion` 关闭

**允许分派子 agent**（像素素材 / 排版 / 动效 / 参考研究），但色板与网格必须由你统一定死再分发，最后由你做一致性审查。

### 7.1 第一轮：程序员视角

**目标**：把代码当成别人写的来审。

**做法**：

1. `git diff` 通读一遍改动，再**从头通读**改过的每个文件。
2. 逐项检查：

| 检查项 | 具体看什么 |
|--------|-----------|
| 事件绑定 | 重构后 `data-*` 选择器是否还能命中；有没有重复绑定监听 |
| 状态兼容 | 旧存档 `zoom: 1/2/3` 能否加载；`settings` 归一化是否接受新值 |
| 边界值 | 滑块拖到 0 与最大值；缩放滚到两端；`ZOOM_STEPS` 越界 |
| 渲染性能 | 是否还在每 tick `innerHTML` 重建列表；滑块是否 rAF 节流 |
| 内存 | 弹窗开关是否重复 addEventListener；`requestAnimationFrame` 是否泄漏 |
| 布局 | 是否还有 `calc(100vh - Npx)`；是否出现第三层滚动条 |
| 可访问性 | 滑块有 `aria-valuetext`；按钮有可读文案；键盘可达 |
| 死代码 | 删掉的功能是否还有残留引用、未使用 import |
| 一致性 | 圆角/边线/间距是否符合规范 |

3. 跑 `npm test`，再补上面列的测试。
4. 打开 DevTools：
   - Console **0 error / 0 warning**
   - Network 无 404
   - Performance 录 10 秒，确认无长任务卡顿

**记录格式**（必须写进交付报告）：

| # | 位置 | 现象 | 根因 | 修复 | 复验 |
|---|------|------|------|------|------|
| 1 | hud.js:533 | 滑块拖到最右报错 | max 写死 10 | 改为 `length-1` | 拖到两端均正常 |

**结束条件**：连续通读两遍，**没有新问题**为止。只审一遍不算完成。
