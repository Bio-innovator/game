# 百日之城 · Hundred-Day City

简体中文 | [English](README.en.md)

一款像素风基地建造与多地图物流增量游戏。建造设施、铺设商路，在一百天内把文明备份送往月背。

在线试玩：https://bio-innovator.github.io/game/

## 背景

太阳风暴之后，地表文明在三十年内崩塌。你是唯一仍在运行的 AI 运算中心，被遗留在一座灰烬平原的地下机房里，唯一指令是「保存文明」。

你没有手脚，只能通过建造设施、铺设商路，把散落在废墟里的资源重新连成一张网。一百天后，日冕脉冲会再次扫过地表——在那之前，你必须把文明备份送抵月背。

## 前 5 分钟

1. 先建 2 座太阳能板（供电）。
2. 再建 2 座废料场（产出废钢）。
3. **不要一开始全建能源站**——能源不产资源，采集才产。这是最容易踩的坑。
4. 资源条左侧是库存，右侧是每秒净变化；为 0 说明产出被下游吃满或被断电压制。
5. 建错了：点地图格子，在右侧详情里使用「拆除」，返还 35% 材料。

首次进入会有 4 步必看引导，按你的实际操作推进：放下太阳能板、放下废料场、废钢达到 20。之后可在「设置 → 关于」重看。

## 为什么我的资源不涨

地图工具栏会直接显示当前诊断，按以下顺序检查：

1. **没有采集设施**：先建废料场、矿井或生物反应器；能源设施本身不产资源。
2. **电力不足**：补充太阳能板、风力机或其他能源设施；持续缺电后高能耗设施会限电。
3. **缺少原料**：例如冶炼厂缺废钢时，检查采集设施是否已建成并正常供电。
4. **等待建造完成**：所有设施仍在施工，等待进度条走完。
5. 以上都正常时显示「网络运转中」。

生物质长期停在 0 不一定是故障：反应器产出被化工厂全部吃掉时，净值就是 0。资源条会同时显示毛产出与毛消耗。

## 操作

- 左侧选择蓝图，点击地图空格建造；大型设施按 2×2 / 3×3 / 5×5 占地，边界外或已有设施时会提示。
- 点击已建成的设施可升级：产出 ×1.6，但灾变受损风险同步上升，风险系数直接写在详情里。
- 地图区按住 Ctrl 滚动滚轮缩放，以光标所在格为锚点；手机端双指捏合缩放，设置面板的 1× / 2× / 3× 按钮为兜底。
- 地图右侧 ▲ / ▼ 切换地下层；顶栏为科研、网络、终局与设置，移动端通过底栏切换建造、地图、科研、物流和日志。
- 存档页支持文件导出/下载、拖拽导入与 Base64 文本兜底；导入前先展示摘要，确认后才覆盖并自动备份。
- 关闭页面后游戏完全暂停：不产出资源、不推进天数、不触发灾变。

## 核心规则

- **断电按比例降产**：供给不足时全图效率为 `供给 / 需求`；连续 30 秒缺电后，高能耗设施优先停机。
- 1 游戏日 ≈ 60 秒（1× 速度）；100 日 ≈ 100 分钟。
- 每张地图有独立电网、库存、灾变压力和中转站；跨图资源只能通过商路运输。
- 商路具有容量、延迟与损耗，可被脉冲切断并付费重连。
- 日冕脉冲提前一天预警，单次对无抗性设施造成 50%~70% 最大耐久伤害；格位累计损毁会提供抗性，加固工程可进一步减免。地下化设施免疫脉冲，产出降至 70%。
- 灰烬风暴每 180~300 秒出现一次，持续 20~30 秒，期间全图产出 50%，屏幕边缘有灰烬粒子。
- 发射流程：发射台 → 火箭装配厂 → 结构装配 → 燃料加注 → 发射 → 月背着陆 → 数据核心建城。
- 三个结局：备份文明、留下（DAY 100 开放）、上传（需意识上传科技）。通关后可进入新周目+，保留科技与运算中心等级。

## 地下与大型设施

- 钻探炸药落地 10 秒后引爆，向下打通一层，并以爆破点为中心开放 3×3 空间。
- 地下支撑可把相邻岩层转为可用地基；地下层最多 3 层。
- 地下无日照、无风暴：太阳能板与风力机不发电，采集类产出 ×1.5。
- 地下会随机塌方，把一格变回岩层并埋掉其上的设施。
- 5×5 的发射台与火箭装配厂、3×3 的轨道电梯与燃料厂、2×2 的装配厂、芯片厂与数据核心，都按整块占地计算相邻加成与伤害。
- 成就与名言会在达成时写入值守日志，完整清单在「设置 → 关于」。

## 存档说明

主存档保存在浏览器 `localStorage`，每 10 秒自动写入。存档页支持导出文件（文件名带日期）、拖拽导入和 Base64 文本。导入前会展示周目、天数、设施数、科技数与保存时间；确认覆盖前会先把当前进度写成带时间戳的本地备份，必要时可恢复上一份。

存档格式为 v2，旧版 v1 存档会自动补齐地下层与尺寸字段后正常加载。

「重新开始」会清除当前周目、地图、科技和主存档，需要二次确认，且不会保留新周目+的科技。
