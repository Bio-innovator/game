# 百日之城 · Hundred-Day City

https://bio-innovator.github.io/game/

## 操作

- 选择左侧建筑蓝图，再点击地图空格建造；点击已完成的同类节点可堆叠。
- 顶栏查看电网、数据、日序与脉冲倒计时；右侧日志记录灾变、物流和科研事件。
- `暂停` 或空格键暂停模拟，速度支持 1× / 2× / 4×，地图支持 1× / 2× / 3× 整数缩放。
- 科技树、网络物流、终局协议和存档管理都在顶栏打开。
- 存档每 10 秒自动写入 `localStorage`，也可在“存档”中导出/导入 Base64 文本。
- 离线收益最多结算 8 小时；离线期间不追溯灾变损伤。

## 核心规则

- **断电按比例降产**：供给不足时全图效率为 `供给 / 需求`；连续 30 秒缺电后，高能耗建筑优先停机。
- 每张地图有独立电网、资源库存、灾变压力和中转站；跨图资源只通过商路运输。
- 商路具有容量、延迟、损耗，可被脉冲切断并付费重连；同一对地图可按不同方向与资源建立多条直连线。
- 日冕脉冲提前一天预警，伤害按格位累计抗性和加固工程减免；地下化建筑免疫脉冲，但产出降至 70%。
- 发射流程：轨道发射台 → 火箭装配厂 → 900 秒结构装配 → 600 燃料加注 → 发射 → 月背着陆 → 数据核心建城。
- 三个结局：备份文明、留下（DAY 100 开放）、上传（需意识上传科技）。通关后可进入新周目+，保留科技与运算中心等级。
