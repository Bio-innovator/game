# 百日之城 · Hundred-Day City

一款像素风基地建造与多地图物流增量游戏。建造节点、铺设商路，在一百天内把文明备份送往月球背面。

[在线试玩](https://bio-innovator.github.io/game/)

## 背景

太阳风暴之后，地表文明在三十年内崩塌。你是唯一仍在运行的 AI 运算中心，被遗留在一座灰烬平原的地下机房里，唯一指令是「保存文明」。

你没有手脚，只能通过建造节点、铺设商路，把散落在废墟里的资源重新连成一张网。

一百天后，日冕脉冲会再次扫过地表——在那之前，你必须把文明备份送到月球背面。

## 前 5 分钟（新手必读）

1. 先建 2 座太阳能板（供电）。
2. 再建 2 座废料场（产废钢）。
3. **不要一开始全建能源站**——没有采集建筑，资源永远是 0。
4. 顶栏「能量」是 `供给 / 需求`，需求超过供给时全图按比例降产。
5. 建错了：开启建造面板顶部的「拆除模式」后点击建筑，或点地图格子使用「拆除」，返还 35% 材料。

首次进入会显示三步引导；之后可在「⚙ 设置 → 关于」中重看。

## 为什么我的资源不涨

地图工具栏会直接显示当前诊断，按以下顺序检查：

1. **没有采集节点**：先建废料场、矿井或生物反应器，能源建筑本身不产资源。
2. **电力不足**：补充太阳能板、风力机或其他能源节点；持续缺电后高能耗建筑会限电。
3. **缺少原料**：例如冶炼厂缺废钢时，检查采集节点是否已建成并正常供电。
4. **等待建造完成**：所有节点仍在施工，等待进度条走完。
5. 以上都正常时显示「网络运转中」。

## 操作

- 选择左侧建筑蓝图，再点击地图空格建造；点击已完成的同类节点可堆叠。
- 建造卡片常显产出与能耗；右侧日志记录灾变、物流和科研事件。
- 空格键暂停模拟。设置面板可调整 1× / 2× / 4× 流速、1× / 2× / 3× 地图缩放、字号和明暗主题。
- 科研、网络、终局与设置位于顶栏；移动端通过底栏切换建造、地图、科研、物流和日志。
- 游戏每 10 秒自动写入浏览器本地存档；设置中的存档页可导出、复制、下载或导入存档。
- 关闭页面后游戏完全暂停：不产出资源、不推进天数、不触发灾变。

## 核心规则

- **断电按比例降产**：供给不足时全图效率为 `供给 / 需求`；连续 30 秒缺电后，高能耗建筑优先停机。
- 1 游戏日 ≈ 60 秒（1× 速度）；100 日 ≈ 100 分钟。关闭页面后游戏暂停，日序不会推进。
- 每张地图有独立电网、资源库存、灾变压力和中转站；跨图资源只通过商路运输。
- 商路具有容量、延迟、损耗，可被脉冲切断并付费重连；同一对地图可按不同方向与资源建立多条直连线。
- 日冕脉冲提前一天预警，伤害按格位累计抗性和加固工程减免；地下化建筑免疫脉冲，但产出降至 70%。
- 发射流程：轨道发射台 → 火箭装配厂 → 900 秒结构装配 → 600 燃料加注 → 发射 → 月背着陆 → 数据核心建城。
- 三个结局：备份文明、留下（DAY 100 开放）、上传（需意识上传科技）。通关后可进入新周目+，保留科技与运算中心等级。

## 存档说明

主存档保存在浏览器 `localStorage`，每 10 秒自动写入。存档页支持 Base64 文本复制与文件下载，也支持粘贴或选择文件导入。导入前会展示周目、天数、建筑数、科技数和保存时间；确认覆盖前会先把当前进度写成带时间戳的本地备份，必要时可恢复上一份备份。

「重新开始」会清除当前周目、地图、科技和主存档，需要二次确认，且不会保留新周目+的科技。
